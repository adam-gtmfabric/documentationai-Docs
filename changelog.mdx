## Upgrading to the Latest Version

Follow these steps to upgrade GTM Fabric smoothly.

<Steps>
  <Step title="Backup Your Data" icon="database">

    Create a full backup of your configuration and partner data.

    ```
    docker-compose down
    cp -r ./data ./backup-$(date +%Y%m%d)
    ```

  </Step>
  <Step title="Update Dependencies" icon="package">

    <CodeGroup tabs="npm,yarn">
      ```bash
      npm install gtm-fabric@latest
      ```
      ```bash
      yarn add gtm-fabric@latest
      ```
    </CodeGroup>

  </Step>
  <Step title="Run Migrations" icon="settings">

    ```
    npm run migrate
    ```

    Review any breaking changes listed above.

  </Step>
  <Step title="Restart Services" icon="zap">

    ```
    docker-compose up -d
    ```

  </Step>
</Steps>

<Callout kind="tip">
  Test in a staging environment first. Check the [migration guide](/introduction#upgrading) for detailed instructions on `v1.1.0` breaking changes.
</Callout>
