## Prerequisites

Before starting, ensure you have:

<Callout kind="info">

- A valid email address for account creation
- Access to your company's partner ecosystem data (CSV exports or API access)
- Google Chrome or Firefox browser (recommended for best experience)
- Optional: Your `API_KEY` from previous integrations

</Callout>

## Create Your Account

Sign up takes under 2 minutes. Follow these steps to get started.

<Steps>
  <Step title="Visit Dashboard" icon="monitor">
    Navigate to `https://dashboard.example.com` and click **Sign Up**.
  </Step>
  <Step title="Enter Details" icon="user">
    Provide your email, company name, and create a strong password.
  </Step>
  <Step title="Verify Email" icon="mail">
    Check your inbox and click the verification link.
  </Step>
  <Step title="Complete Setup" icon="check-circle">
    Accept terms and set your time zone.
  </Step>
</Steps>

## Complete Onboarding Wizard

The wizard guides you through initial configuration.

<Steps>
  <Step title="Connect Data Sources" icon="database">
    Upload partner lists or connect via API. Supported formats include CSV and JSON.
  </Step>
  <Step title="Define ICP" icon="target">
    Enter your Ideal Customer Profile criteria like industry, revenue range, and tech stack.
  </Step>
  <Step title="Review Summary" icon="eye">
    Preview your setup and click **Finish**.
  </Step>
</Steps>

## Generate Initial ICP Insights

Use the API to fetch your first insights programmatically.

<CodeGroup tabs="cURL,JavaScript,Python">
  ```bash
  curl -X POST https://api.example.com/v1/insights/generate \
    -H "Authorization: Bearer YOUR_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "icp": {
        "industry": "SaaS",
        "revenue_min": 10000000,
        "tech_stack": ["Salesforce", "HubSpot"]
      }
    }'
  ```
  ```javascript
  const response = await fetch('https://api.example.com/v1/insights/generate', {
    method: 'POST',
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY',
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({
      icp: {
        industry: 'SaaS',
        revenue_min: 10000000,
        tech_stack: ['Salesforce', 'HubSpot']
      }
    })
  });
  const insights = await response.json();
  console.log(insights);
  ```
  ```python
  import requests

  response = requests.post(
      'https://api.example.com/v1/insights/generate',
      headers={
          'Authorization': 'Bearer YOUR_API_KEY',
          'Content-Type': 'application/json',
      },
      json={
          'icp': {
              'industry': 'SaaS',
              'revenue_min': 10000000,
              'tech_stack': ['Salesforce', 'HubSpot']
          }
      }
  )
  insights = response.json()
  print(insights)
  ```
</CodeGroup>

<Response tabs="200">
```json

  "success": true,

      "partner": "Acme Corp",
      "match_score": 0.92,
      "predicted_revenue": 250000,
      "recommendation": "Prioritize joint ICP alignment"
    }
  ]
}
```
</Response>

<Callout kind="tip">

Replace `YOUR_API_KEY` with your actual key from the dashboard settings. Store it securely.

</Callout>
